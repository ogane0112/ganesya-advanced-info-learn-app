# 科目A(旧午前)対策問題

`questions.json` は応用情報技術者試験 科目A 向けのオリジナル四肢択一問題 500問(過去問の転載ではない)。
配分はテクノロジ 312 / マネジメント 63 / ストラテジ 125(本番の 50:10:20 に合わせた比率)。

| キー | 内容 |
|---|---|
| `id` | 問題ID(分類の略号 + 連番) |
| `area` / `topic` | 大分類 / 中分類(シラバスに準拠) |
| `calc` | 計算問題なら true |
| `new` | 新シラバス(AI・データサイエンス・DX など)の論点なら true |
| `q` / `c` / `a` | 問題文 / 選択肢4つ(ア〜エ) / 正解の添字(0〜3) |
| `e` | 解説(選択肢を「アは〜」のように記号で参照) |

計算問題の正解はすべて計算で検証済み。正解位置はア〜エ各125問に揃えてある。
