## 本文

この問題は採点フローの動作確認用に作成したオリジナル問題です。実際の過去問に差し替えて使ってください。

昇順に整列された整数型の配列 `data`(要素番号は 1 から始まる)から、値 `target` を探す関数 `binarySearch` を考える。見つかった場合はその要素番号を、見つからなかった場合は -1 を返す。

```
○整数型: binarySearch(整数型の配列: data, 整数型: target)
  整数型: low ← 1
  整数型: high ← data の要素数
  整数型: mid
  while (low ≦ high)
    mid ← (low + high) ÷ 2 の商
    if (data[mid] が target と等しい)
      return mid
    elseif (data[mid] が target より小さい)
      low ← [ ア ]
    else
      high ← [ イ ]
    endif
  endwhile
  return -1
```

| 用語 | 説明 |
|---|---|
| 線形探索 | 先頭から順に1要素ずつ比較する探索 |
| 二分探索 | 探索範囲を半分ずつ絞り込む探索 |
